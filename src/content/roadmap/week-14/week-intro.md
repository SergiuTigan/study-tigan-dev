# Week 14 — Project #1: Build, Ship, Demo

> *"A portfolio project isn't done when the code works. It's done when a stranger can understand it in 60 seconds."*

**Dates:** 18-24 August 2025
**Hours:** 18h total
**Phase:** Faza 4 — Portfolio + Job Hunt
**Focus:** First Major Portfolio Project

---

## The Shift

You've spent 13 weeks learning. Absorbing. Building small things. Understanding how the pieces fit.

That's over now.

This week, you build something real. Something you'd be proud to demo in an interview. Something that lives on the internet with a URL anyone can visit, a README anyone can read, and a demo video that makes a hiring manager pause their scroll.

You're picking one project from your shortlist — Dobby AI, Iron Pulse AI Coach, AI Customer Support Platform, or Luppy AI Vet Assistant — and you're shipping it in 6 days.

## The Cadence

This week follows a battle-tested project sprint:

| Day | Focus | Hours | Deliverable |
|-----|-------|-------|-------------|
| **Day 92** (Mon) | Plan + Architecture | 2h | Architecture doc, wireframes, data model |
| **Day 93** (Tue) | Backend Scaffold + AI Core | 2h | Working API endpoints, database, AI integration |
| **Day 94** (Wed) | Frontend Scaffold | 2h | Pages, components, layout, basic styling |
| **Day 95** (Thu) | Core AI Flow | 2h | End-to-end: input → AI → output working |
| **Day 96** (Fri) | REST | — | Recharge |
| **Day 97** (Sat) | Polish + Deploy | 4h | Error handling, responsive UI, live on Vercel |
| **Day 98** (Sun) | README + Demo + Ship | 6h | Professional README, Loom video, final push |

## Why This Order Matters

Monday is planning because you need clarity before code. Tuesday-Wednesday build the skeleton. Thursday is the critical day — the moment your app actually *does the thing*. Friday rest is strategic (your subconscious will solve bugs). Saturday polishes. Sunday packages it for the world.

## Choosing Your Project

Pick the one that:
1. **Excites you** — you'll need that energy on Thursday when the AI flow breaks
2. **Shows range** — if your other two projects are chatbots, pick the coach or vet assistant
3. **Has a clear demo story** — can you show the value in a 2-minute video?

## Quality Bar

By Sunday night, this project should have:
- A live URL anyone can visit
- A README that explains the what, why, and how in under 2 minutes of reading
- A 2-3 minute demo video showing the core flow
- Clean, well-structured code a reviewer would respect
- At least one "wow" moment in the AI interaction

## The Mindset

You're not a student building a homework assignment. You're an engineer shipping a product. Every decision this week should pass one filter: *"Would this impress me if I saw it on someone's portfolio?"*
