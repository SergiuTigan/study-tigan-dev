# Day 106 — Plan + Architecture + Wireframe (Project #3)

> *"Plan like an architect. This one goes in the portfolio highlight reel."*

**Date:** Monday, 1 September 2025
**Hours:** 2h · Evening session
**Topic:** Project #3 Architecture & Planning
**Phase:** Faza 4 — Portfolio + Job Hunt · Week 16

---

## What You're Doing

Third time planning a project in three weeks. You should be able to produce an architecture doc in your sleep by now. The difference today: invest more time in the AI design and the story you'll tell about this project.

This project will likely be the first one you show in interviews. Plan accordingly.

## The Work

### 1. Architecture Doc (30 min)

Same format, highest quality. Include:

- **Problem statement** — what real-world problem does this solve?
- **Target user** — who benefits and why should they care?
- **Technical architecture** — full system diagram
- **AI strategy** — models, patterns, data flow, prompt design
- **Data model** — entities, relationships, what persists
- **Deployment plan** — infra, env vars, monitoring

### 2. The Interview Story (15 min)

Write down answers to these questions now — you'll need them in Week 19:
- "What's the most technically challenging thing about this project?"
- "Why did you choose this architecture over alternatives?"
- "What would you change if you had more time?"
- "What metrics prove this works?"

### 3. User Flows (15 min)

Map the demo flow with extreme precision. Every click, every screen, every AI interaction. This is the flow you'll record on Sunday and demo in interviews.

### 4. Component Breakdown (10 min)

You know the pattern. List components, note reuse from previous projects, identify new ones.

### 5. Wireframe (15 min)

Sketch fast. Focus on information hierarchy — what does the user see first, second, third?

### 6. AI Integration Design — Advanced (35 min)

Push beyond what you've done:

**Consider combining patterns:**
- RAG + tool use (retrieve documents AND call APIs)
- Multi-model orchestration (use different models for different tasks)
- Evaluation/feedback loops (measure and improve AI output quality)
- Streaming + structured output (stream a response while also returning structured data)

**Plan your prompt architecture:**
- System prompt with role, constraints, output format
- Few-shot examples for consistent output
- Dynamic context injection (user data, retrieved docs, tool results)
- Error recovery prompts ("If the user's input is unclear, ask for clarification")

## Key Insight

The best portfolio projects aren't the most complex. They're the ones with the clearest story. "I built X because Y. It uses Z architecture because W. The result is Q." If you can tell that story clearly, the project will carry you through interviews.
