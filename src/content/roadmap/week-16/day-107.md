### 2. AI Core — Your Most Advanced (75 min)

This is where you push boundaries. Implement the advanced pattern from yesterday's architecture:

**Multi-model orchestration:**
```typescript
// Fast model for classification/routing
const classification = await generateText({
  model: openai('gpt-4o-mini'),
  prompt: `Classify this request: ${input}`,
});

// Powerful model for complex generation
const result = await streamText({
  model: openai('gpt-4o'),
  system: systemPromptFor(classification),
  messages,
});
```

**RAG with reranking:**
```typescript
// 1. Embed query
// 2. Vector search (top 20)
// 3. Rerank with cross-encoder or LLM (top 5)
// 4. Inject into prompt with source metadata
```

**Tool use with validation:**
```typescript
// 1. Define tools with Zod schemas
// 2. AI decides which tool to call
// 3. Execute tool with error handling

```

### 3. Database Schema (15 min)

Design a schema that supports your advanced features:
- Conversation history with metadata

- AI interaction logs (for later analysis)
- Any domain-specific entities

### 4. Integration Test (20 min)

Test the complete AI pipeline:
- [ ] Basic request → response works
- [ ] Advanced pattern executes correctly
- [ ] Edge cases handled (bad input, missing data, timeout)
- [ ] Response quality is high
- [ ] Latency is acceptable

## Tips for Efficiency

- **Reuse everything that isn't project-specific.** Error handling, response formatting, database utils — copy from Projects 1 and 2.
- **Build the happy path first.** Get the sophisticated flow working for the ideal input. Handle edge cases Saturday.
- **Measure latency from day one.** Advanced patterns can be slow. Know your numbers.
