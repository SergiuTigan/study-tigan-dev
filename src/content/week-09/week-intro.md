## Why This Week Exists

You have eight years of Angular. You can build anything with it. So why are we spending a week on React and Next.js?

Because the AI ecosystem chose React.

Vercel's AI SDK, the most mature toolkit for building AI-powered UIs, is React-first. LangChain's UI components are React. Every AI demo, every tutorial, every starter template -- React. You could fight this. You could build Angular wrappers. You could port libraries. Or you could spend one compressed week learning React through the lens of someone who already understands components, state management, lifecycle hooks, and reactive programming.

This is not "learn React from scratch." This is "translate Angular fluency into React fluency."

## The Angular Developer's Advantage

Here is the thing nobody tells Angular developers: you are actually overqualified for React. Angular taught you dependency injection, RxJS, complex state management, module architecture, and strict typing. React is simpler. Deliberately simpler. Where Angular gives you a framework with opinions about everything, React gives you a library and says "figure it out."

Your challenge this week is not complexity. It is simplicity. You will keep reaching for Angular patterns that do not exist in React because React solved those problems differently -- or decided they were not problems at all.

## The Week Arc

**Monday-Tuesday:** React fundamentals and Next.js App Router. The translation from Angular concepts to React equivalents. Server Components will be the one truly new concept -- Angular has nothing like them.

**Wednesday:** Server Actions. This will feel like magic after years of writing HttpClient calls and API services.

**Thursday:** Build a chat app with raw API calls. No AI SDK yet. Prove you can build it manually first.

**Saturday:** AI SDK introduction. Replace your manual code with the proper toolkit. See why it exists.

**Sunday:** Deep dive into multi-provider support and rich tool use. Polish everything.

## What Success Looks Like

By Sunday night, you will have a working AI chat application built with Next.js and the Vercel AI SDK. It will support streaming responses, tool use, and multiple AI providers. More importantly, you will understand the React + Next.js mental model well enough to build any AI-powered frontend.

You are not becoming a React developer. You are becoming an AI engineer who can use React when the ecosystem demands it.
