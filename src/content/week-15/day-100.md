## The Work

### 1. Project Scaffold (15 min)

```bash
npx create-next-app@latest project-2-name --typescript --tailwind --eslint --app --src-dir
cd project-2-name
npm install ai @ai-sdk/openai zod
```

Add any project-specific dependencies:
- RAG: `npm install @pinecone-database/pinecone` or pgvector setup
- Tool use: schema libraries, external API clients
- Database: `npm install prisma @prisma/client`

Copy your `.env.local` template from Project #1. Update values.

### 4. Test the Core (25 min)

## Tips for Efficiency

- **Reuse your Project #1 structure.** Same folder layout, same API route patterns, same error handling approach.
- **Don't over-engineer the AI pattern.** Get basic RAG/tool use working. Optimize later.
- **If RAG is slow on setup, use a small test dataset.** 10-20 documents max for development.
- **Test with cheap models first.** GPT-4o-mini for development, switch to GPT-4o for the demo.
