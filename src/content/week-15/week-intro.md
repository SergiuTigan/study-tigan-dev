## The Difference This Week

Last week you figured out the cadence. This week you execute it faster.

You already know the rhythm: plan Monday, backend Tuesday, frontend Wednesday, integrate Thursday, rest Friday, polish Saturday, ship Sunday. The structure is identical. What changes is your speed, your confidence, and your project choice.

## Choosing Project #2

Pick a project that **contrasts** with Project #1:

| If Project #1 was... | Project #2 should be... |
|---|---|
| Conversational (chatbot-style) | Tool/dashboard-based |
| Consumer-facing | B2B or professional |
| Single-model | Multi-model or RAG-based |
| Simple prompt engineering | Agent/tool-use patterns |

The goal is portfolio diversity. An interviewer should look at your three projects and see range — not three variations of the same chatbot.

## What You Should Do Differently

1. **Plan faster.** You've done this before. 45 min max on architecture.
2. **Reuse patterns.** Same project scaffold, same AI SDK setup, same component library approach.
3. **Different AI pattern.** If Project #1 was simple chat completion, try RAG, tool use, or multi-step agents.
4. **Higher quality bar.** Project #2 should be visibly better than Project #1.

## Quality Bar (Higher Than Last Week)

- Live URL with zero bugs in the demo flow
- README with architecture diagram
- Demo video under 3 minutes, scripted
- At least one technical differentiator (RAG, tool use, multi-model, etc.)
- Responsive, polished UI
- GitHub stars potential (is it useful to others?)
