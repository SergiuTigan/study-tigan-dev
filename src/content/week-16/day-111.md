## What You're Doing

## The Work

### Hours 1-2: Premium Polish (120 min)

**UI Quality — Portfolio Grade**
- [ ] Visual hierarchy is immediately clear
- [ ] Color usage is intentional (not just "it's blue because default")
- [ ] Typography creates rhythm (heading sizes, body text, captions)
- [ ] Spacing is consistent and generous
- [ ] Icons are consistent (all from the same set)
- [ ] Dark mode works if applicable

**AI Output Polish**
- [ ] Markdown rendering is beautiful (lists, bold, code blocks)
- [ ] Long responses are scrollable with clear boundaries
- [ ] Sources/references are clickable and well-formatted (if RAG)
- [ ] Tool results are displayed clearly (if tool use)
- [ ] Multi-step processes have clear progress indicators

**Interaction Polish**
- [ ] Form validation with helpful error messages
- [ ] Keyboard shortcuts work (Enter to send, Escape to cancel)
- [ ] Focus management is correct (input auto-focuses after response)
- [ ] Scroll behavior is natural
- [ ] No layout shifts during loading

### Hour 3: Comprehensive Edge Cases (60 min)

Test everything that could go wrong during a demo:
- [ ] First-time user experience (no history, no context)
- [ ] Rapid interactions (send 5 messages quickly)
- [ ] Very long AI response
- [ ] AI returns unexpected format
- [ ] Network interruption mid-response
- [ ] Browser back/forward navigation
- [ ] Page refresh preserves state (or gracefully resets)
- [ ] Multiple tabs open simultaneously

### Hour 4: Deploy + Cross-Project Verification (60 min)

**Deploy Project #3:**
```bash
npm run build && npx vercel --prod
```

**Post-deploy:**
- [ ] Production URL works
- [ ] All features functional
- [ ] Performance acceptable (Lighthouse audit)
- [ ] Mobile works properly

**Cross-Project Check (important):**
- [ ] Project #1 still deployed and working
- [ ] Project #2 still deployed and working
- [ ] All three have distinct URLs
- [ ] All three are pinned on GitHub
