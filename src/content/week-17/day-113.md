# Day 113 — LinkedIn Headline + About Section

> *"Your LinkedIn headline is a 120-character pitch. Make every character count."*

**Date:** Monday, 8 September 2025
**Hours:** 2h · Evening session
**Topic:** LinkedIn Profile — Top Section
**Phase:** Faza 4 — Portfolio + Job Hunt · Week 17

---

## What You're Doing

Today you update the two most important parts of your LinkedIn profile: the headline and the About section. These are what recruiters see first. They determine whether someone clicks into your profile or scrolls past.

Your current headline probably says something like "Senior Frontend Developer" or "Angular Engineer." By tonight, it'll say AI Engineer.

## The Work

### 1. Profile Photo + Banner (15 min)

**Photo:** Professional, recent, friendly. If you don't have one, take one against a plain background with good lighting. No selfies.

**Banner:** Create a simple one in Canva (free):
- Your name + "AI Engineer"
- Optional: tech stack icons or a screenshot of your project
- Keep it clean. Dark background + white text works.

### 2. Headline (20 min)

Your headline appears everywhere — search results, comments, connection requests. It needs to be immediately clear.

**Template:**
```
AI Engineer | Full-Stack TypeScript + LLMs | Building AI-Powered Products
```

**Variations:**
```
AI Engineer | Building with LLMs, RAG & Agents | TypeScript + Python
```
```
AI Engineer | From Senior Frontend to AI Products | Next.js + OpenAI + Vercel AI SDK
```
```
AI Software Engineer | Full-Stack + LLMs | Shipped 3 AI Products in 4 Months
```

**Rules:**
- "AI Engineer" must be the first thing
- Include your tech stack
- Include a differentiator or proof point
- No buzzwords without substance ("passionate innovator")
- Under 120 characters if possible

### 3. About Section (60 min)

This is your pitch. Structure it clearly:

```
I build AI-powered products.

After [X] years as a Senior Frontend/Full-Stack Engineer, I spent 4 months
doing a structured deep dive into AI engineering — LLMs, RAG systems,
AI agents, prompt engineering, and production AI deployment.

What I built:
- [Project 1]: [one-line description] → [Live URL]
- [Project 2]: [one-line description] → [Live URL]
- [Project 3]: [one-line description] → [Live URL]

My stack:
TypeScript · Next.js · React · Node.js · Python
OpenAI · Anthropic · Vercel AI SDK · LangChain
Prisma · Supabase · PostgreSQL · Pinecone
Vercel · Docker · Git

What I'm looking for:
AI Engineer or Full-Stack Engineer roles at companies building
AI-powered products. Especially interested in: [2-3 company types
or product areas].

Let's connect: [email] · [portfolio URL] · [GitHub URL]
```

**Quality Checks:**
- Reads in under 60 seconds
- Projects are linked and clickable
- Tech stack is specific and current
- "What I'm looking for" is clear
- Contact info is easy to find

### 4. Enable "Open to Work" (10 min)

Go to Settings → Job seeking preferences:
- Turn on "Open to Work"
- Set to visible to recruiters only (or public if you prefer)
- Job titles: "AI Engineer", "Full-Stack Engineer", "Software Engineer"
- Location: your city + "Remote"
- Start date: Immediately

### 5. Location & Contact Info (15 min)

- Location set correctly
- Email visible (or LinkedIn messaging enabled)
- Website/portfolio link added
- GitHub link added

## Key Insight

Recruiters spend 6 seconds on a LinkedIn profile. Your headline and first two lines of the About section must hook them in that time. "AI Engineer who shipped 3 projects" is infinitely more compelling than "Passionate developer seeking opportunities."

## Done When

- [ ] Profile photo is professional
- [ ] Banner image created and uploaded
- [ ] Headline updated with "AI Engineer" + stack
- [ ] About section written, formatted, and includes project links
- [ ] "Open to Work" enabled
- [ ] Contact info and links updated
- [ ] You've read the profile as a stranger would — does it convince?
