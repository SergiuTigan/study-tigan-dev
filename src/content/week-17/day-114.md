# Day 114 — LinkedIn Experience Section

> *"Your past experience isn't a liability. It's the foundation that makes your AI transition credible."*

**Date:** Tuesday, 9 September 2025
**Hours:** 2h · Evening session
**Topic:** LinkedIn Experience & Skills Update
**Phase:** Faza 4 — Portfolio + Job Hunt · Week 17

## What You're Doing

Today you update your LinkedIn work history. You're not erasing your past — you're reframing it. A senior engineer who transitions to AI is more credible than someone with zero engineering experience. Your history is an asset. Present it that way.

## The Work

### 1. Add New Entry: AI Engineering (45 min)

Create a new experience entry:

**Title:** AI Engineer (Self-Directed Transition)
**Company:** Independent / Your name
**Duration:** June 2025 - Present
**Location:** [Your city] · Remote

**Description:**
```
Completed a structured 4-month AI engineering program, shipping 3
production-quality AI applications from concept to deployment.

Key projects:
• [Project 1 name] — [what it does]. Built with [stack]. [metric if available].
  Live: [URL]
• [Project 2 name] — [what it does]. Built with [stack]. [metric if available].
  Live: [URL]
• [Project 3 name] — [what it does]. Built with [stack]. [metric if available].
  Live: [URL]

Technical depth:
• Prompt engineering, RAG pipelines, AI agents, tool use
• Production AI deployment with monitoring and cost optimization
• LLM evaluation and testing methodologies
• Full-stack AI application development (Next.js + AI SDKs)
```

**Add media:** Link to each project's live URL or demo video.

### 2. Reframe Existing Experience (45 min)

For each previous role, add AI-relevant framing where honest:

**Senior Frontend/Full-Stack Engineer at [Company]:**
- Did you build any data-driven features? Mention ML/analytics adjacent work.
- Did you work with APIs? Emphasize API integration skills (same skills used with AI APIs).
- Did you optimize performance? Connects to AI cost/latency optimization.
- Did you build complex UIs? Connects to building AI-powered interfaces.

**Example reframe:**
```
Before: "Built responsive web applications using Angular and TypeScript"
After: "Architected complex data-driven web applications processing
real-time user interactions — skills directly applied to building
AI-powered product interfaces"
```

Don't lie. Don't stretch. But do draw the lines between past work and AI engineering. Recruiters are looking for these connections.

### 3. Skills Section (15 min)

**Add these skills:**
- Artificial Intelligence
- Large Language Models (LLMs)
- Prompt Engineering
- RAG (Retrieval-Augmented Generation)
- AI Agents
- OpenAI API
- Vercel AI SDK
- LangChain
- Vector Databases

**Keep your existing skills.** TypeScript, React, Node.js, etc. are still valuable. They show full-stack capability.

**Reorder:** Put AI-related skills near the top.

### 4. Ask for Endorsements (15 min)

Message 3-5 colleagues:
```
Hey [name], I've been transitioning into AI engineering over the
past few months and updated my LinkedIn profile. Would you be willing
to endorse a few of my skills? Happy to return the favor!
```

Focus on endorsements for technical skills, not soft skills.

## Key Insight

The "self-directed transition" entry is your secret weapon. It shows initiative, self-discipline, and results. Most people talk about learning AI. You shipped three products. That entry — with live links and metrics — does more work than a traditional job entry.
