## What You're Doing

Today you turn your GitHub profile into a portfolio landing page. When someone visits github.com/yourusername, they should immediately understand who you are, what you build, and what your best work looks like.

## The Work

### 1. Create Profile README Repository (10 min)

If you haven't already:
```bash
# Create a repo with the same name as your GitHub username
# This repo's README.md appears on your profile page
```

Go to GitHub → New Repository → Name it `yourusername` → Add a README → Create.

### 3. Pin Repositories (15 min)

Go to your profile → "Customize your pins":
- Pin all 3 AI project repos
- Add 1-2 other strong repos if you have them (open source contributions, utilities)
- Remove any pinned repos that don't represent your current skills

For each pinned repo, ensure:
- Description is clear and compelling (shown on profile)
- Topics/tags are set (shown as labels)
- Language is detected correctly

### 4. Repository Polish (25 min)

Quick pass on each project repo:

**Repository Settings:**
- [ ] Description filled in (short, compelling)
- [ ] Website URL set (live demo link)
- [ ] Topics added: `ai`, `nextjs`, `typescript`, `openai`, `rag`, etc.
- [ ] Social preview image set (screenshot of your app)

**README Check:**
- [ ] All links work
- [ ] Screenshots display correctly
- [ ] Getting started instructions are current
- [ ] Demo video links work

### 5. Clean Up Old Repos (10 min)

- Archive or make private any repos that don't represent you well
- Remove or unpin tutorial/course repos
- Keep forks only if you made meaningful contributions

## Key Insight

Hiring managers and senior engineers review GitHub profiles differently than LinkedIn. They look for: code quality in pinned repos, README professionalism, project diversity, and recent activity. Your profile README is the first thing they see — make it a curated portfolio, not a diary.
