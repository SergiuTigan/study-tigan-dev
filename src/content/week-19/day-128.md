## What You're Doing

Prepare for coding interviews. For AI engineer roles, coding rounds are typically less intense than SWE roles — but they still exist, especially at larger companies. Focus on the patterns that come up most: arrays, strings, hash maps, and async patterns.

You're a senior engineer. You know how to code. This is about practicing the *interview format* — solving problems under a timer with clean code.

## The Work

### What to Focus On (and What to Skip)

**DO practice:**
- Arrays and strings (two pointers, sliding window)
- Hash maps and sets (frequency counting, lookup)
- Basic trees and graphs (BFS, DFS)
- Async patterns (promises, concurrent API calls)
- TypeScript/Python specifics for your interview language

**DON'T waste time on:**
- Hard dynamic programming
- Advanced graph algorithms (Dijkstra, etc.)
- Bit manipulation
- Esoteric data structures (tries, segment trees)

AI engineer roles rarely test these. Your time is better spent on system design and AI-specific prep.

### Warm-Up: Easy Problems (30 min)

Solve 3-4 easy problems to get in the groove. 7-8 min each:

1. **Two Sum** — hash map lookup
2. **Valid Parentheses** — stack
3. **Merge Two Sorted Lists** — pointer manipulation
4. **Best Time to Buy and Sell Stock** — single pass

Use LeetCode, NeetCode, or HackerRank. Solve in your interview language (TypeScript or Python).

### Core Practice: Medium Problems (60 min)

Solve 3-4 medium problems. 15-20 min each:

1. **Group Anagrams** — hash map with sorted key
2. **3Sum** — two pointers
3. **LRU Cache** — hash map + doubly linked list (common in system design)
4. **Top K Frequent Elements** — hash map + heap or bucket sort

**For each problem:**
1. Read and understand (2 min)
2. Plan your approach before coding (3 min)
3. Code the solution (10-12 min)
4. Test with examples (2-3 min)
5. Analyze time/space complexity

### AI-Relevant Coding Patterns (30 min)

Practice patterns that come up in AI engineering specifically:

**Async API calls (common in AI apps):**
```typescript
// Process items with rate limiting
async function processWithRateLimit(items: string[], maxConcurrent: number) {
  const results = [];
  for (let i = 0; i < items.length; i += maxConcurrent) {
    const batch = items.slice(i, i + maxConcurrent);
    const batchResults = await Promise.all(
      batch.map(item => callAIEndpoint(item))
    );
    results.push(...batchResults);
  }
  return results;
}
```

**Text processing (relevant to RAG/embeddings):**
```typescript
// Chunk text with overlap
function chunkText(text: string, chunkSize: number, overlap: number): string[] {
  const chunks = [];
  for (let i = 0; i < text.length; i += chunkSize - overlap) {
    chunks.push(text.slice(i, i + chunkSize));
  }
  return chunks;
}
```

**Similarity/ranking:**
```typescript
// Cosine similarity between vectors
function cosineSimilarity(a: number[], b: number[]): number {
  const dotProduct = a.reduce((sum, val, i) => sum + val * b[i], 0);
  const magnitudeA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0));
  const magnitudeB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0));
  return dotProduct / (magnitudeA * magnitudeB);
}
```

## Key Insight

For AI engineer roles, coding is a filter — not the differentiator. They want to confirm you can code competently. Your differentiator is system design and AI knowledge. Spend enough time on coding to pass the filter, then invest the rest in what sets you apart.
